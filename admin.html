Draft & cadangan

Unduh cadangan sebelum mengganti konten. Impor hanya mengubah draft editor; terbitkan setelah diperiksa. Mode pratinjau menyimpan data hanya di browser ini.

Profil & foto

Nama, perkenalan, pendidikan, dan ringkasan profil.

Unggah memakai Firebase Storage (Blaze). Proporsi foto dan transparansi dipertahankan; sisi panjang maksimal 1200 piksel. URL HTTPS dapat digunakan tanpa Storage.

Foto baru tampil di website setelah perubahan diterbitkan. Foto yang sudah terunggah bersifat publik; menghapusnya dari profil tidak menghapus arsip file di Storage.

Pengalaman kerja

Tambah, edit, hapus, atau ubah urutan. Baris teratas ditampilkan lebih dahulu.

Kontak

Kontak ini tampil publik di bagian Kontak dan tombol hero. Nomor WhatsApp berisi digit saja, termasuk kode negara tanpa tanda +.

Proyek & galeri

Setiap proyek bisa memiliki beberapa gambar. Di website, gambar pertama menjadi sampul dan klik gambar membuka detail proyek. Tulis satu gambar per baris: URL HTTPS atau path assets/…, lalu caption opsional setelah " | ".

Maksimal 50 proyek per dokumen. Semua metadata tetap mengikuti batas keamanan dokumen 150 KB. File gambar disimpan terpisah di Storage. Menghapus proyek atau URL tidak menghapus file Storage secara permanen.
